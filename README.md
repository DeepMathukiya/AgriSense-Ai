## Overview
**AgriSense AI** is an AI-powered platform designed to help farmers identify crop diseases, improve agricultural productivity, and make informed decisions. The platform leverages **machine learning** and **augmented reality (AR)** technologies to detect and diagnose plant diseases from leaf images, providing real-time solutions for pest management and crop health improvement.

The system includes a **CNN-based model** for disease prediction and an **AR feature** that visually presents disease information, making it easy for farmers to take immediate action.

## Features
- **Disease Detection**: Uses AI to analyze leaf images and predict crop diseases accurately.
- **AR Integration**: Provides augmented reality-based visualizations, allowing farmers to scan crops and receive detailed disease insights.
- **Crop Health Monitoring**: Monitors crop health by analyzing images and predicting possible diseases early.
- **Data-Driven Insights**: Provides actionable insights based on historical data and disease trends.
- **User-Friendly Interface**: Designed with simplicity to ensure farmers can easily use the platform without technical knowledge.

## Technologies Used
- **Machine Learning**: Convolutional Neural Networks (CNN) for disease prediction from leaf images.
- **Augmented Reality (AR)**: ARCore/ARKit for visualizing disease data in real-time.
- **Web Framework**: Flask/Django for backend development.
- **Mobile App Development**: Flutter for cross-platform mobile app (iOS & Android).
- **Image Processing**: OpenCV for image preprocessing and augmentation.
- **Cloud**: AWS/GCP for cloud deployment and storage.
